# AGENTS.md

This repo's agent instructions live in [`/CLAUDE.md`](CLAUDE.md) and in per-folder `CLAUDE.md` files throughout the tree. Read those. The master picture of what the app does and what's left to build is [`/spec.md`](spec.md).

`AGENTS.md` exists so that any agent following the [open AGENTS.md standard](https://agents.md) — regardless of which tool or model is running it — is pointed at the same rules. The conventions in `CLAUDE.md` apply to all agents equally; there is one source of truth, and this file defers to it.
