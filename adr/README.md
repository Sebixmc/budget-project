# /adr

Architecture Decision Records, numbered sequentially (`001-`, `002-`, …). Each ADR captures the context, decision, consequences, and alternatives for a choice that is hard to reverse or spans multiple modules. Start any new ADR from `000-template.md`. See `CLAUDE.md` in this folder for the rules; once merged, ADRs are immutable. Use the `/new-adr` command to scaffold one.

The first three ADRs here were seeded from the "Decisions Log" in [`/spec.md`](../spec.md) — they record decisions the project had already made informally.
